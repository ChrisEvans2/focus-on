# Focus On · 专注时刻

基于已有 Figma 界面的 macOS 专注工具。React + TypeScript 保留任务/圆盘界面，Swift + AVFoundation + Vision 在本机结合头部与近似视线判断持续偏离或离席，并通过屏幕中央的灰绿色小宠物提醒。宠物循环眨眼、上下左右看，鼠标可穿透、不抢焦点；回看稳定后自动消失，支持系统减少动态效果。

## 运行 macOS 应用

```sh
npm install
npm run mac:build
npm run mac:open
```

产物：`build/Focus On.app`。需要 macOS 13+ 和 Swift Command Line Tools；不依赖完整 Xcode，也不需要后台服务器。首次开始任务时会请求摄像头权限，随后自动观察约 6 秒建立头部与眼部基准，无需逐点校准。暂停、休息、结束、关窗口或退出时关闭摄像头。画面不保存、不上传。拒绝授权仍可计时。

开始后自动观察约 6 秒适应坐姿，无需逐点校准；小幅稳定变化会缓慢适应。设置中可关闭摄像头提醒、重新适应坐姿或重试。持续偏头约 7 秒、可靠的视线偏离累计约 10 秒、离席约 9 秒触发，回正约 1.5 秒自动消失，随后冷却 25 秒。眼部点位不足时退回头部判断，不能识别真实注意力或手机；启动时一直低头或明显改变机位仍可能需要主动纠正基线。

`npm run test:native` 验证 Swift 检测与时间规则；`npm run test:mac` 运行不申请摄像头的原生集成测试。实现边界、实机验收和打包说明见 [macOS MVP 文档](docs/macos-mvp.md)。

## 眼动测试（实验）

**在 VS Code 查看真实画面上的瞳孔和眼睑标记：** 终端运行 `npm run gaze:debug`，在独立窗口点击「开始摄像头」，可勾选「放大眼部」。与正式 App 共享检测代码，不需要部署模型。见 [实时视线调试说明](docs/gaze-debug.md)。

设置 → **眼动测试（实验）** → 开始测试。分别采样屏幕中央和键盘，观察瞳孔位置是否有稳定差异；结果暂不触发提醒。见 [眼动测试说明](docs/eye-test.md)。

## 浏览器预览

浏览器版提供任务和计时；摄像头与跨应用提醒需使用 macOS app。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 检查类型并生成生产构建；`npm test` 运行 Playwright 测试（使用本机 Google Chrome）。

## 交互

- 无任务：时钟居中。输入任务后直接点击“开始任务”，即可添加任务并启动计时，同时时钟缩小移向右侧、任务列表出现。Enter 仍可只添加任务。输入框和开始任务按钮始终保持原位。待办列表固定四行，长标题单行省略（悬停显示全文）；超过四项且下方还有内容时显示底部滚动阴影。
- 圆盘每圈 60 分钟：12 个大刻度，每组之间 4 个小刻度。拖动圆点，以 1 分钟为步长，最多 120 分钟；第二圈显示内侧进度环。
- 点击圆环可定位当前圈时间；方向键调 1 分钟，Page Up / Down 调 5 分钟，Home / End 选择 1 / 120 分钟。旁边的加减按钮每次调 5 分钟。
- 圆盘选择的是含休息的总时长。35 分钟以下不拆分；满 35 分钟后从总时长扣除休息，各段专注等长且不超过 25 分钟，段间休息 5 分钟。35 分钟为 15 + 5 + 15；55 分钟为 25 + 5 + 25；60 分钟为三段 16:40 加两次 5 分钟休息；120 分钟为五段 20 分钟加四次 5 分钟休息。
- 开始后圆盘显示当前阶段倒计时，休息及第二段自动切换；暂停时保留进度，重置后可重新调整时长。
- `⌘ Enter` 开始 / 暂停，Enter 添加任务。任务可完成、排队或切换，计时期间不允许手动切换队列中的任务。
- macOS 主界面右上角、设置齿轮左侧的“−”按钮：直接最小化到菜单栏并继续计时。菜单栏只显示计时器图标；悬停约 0.2 秒展开 272 × 224 的紧凑面板，显示当前任务、轮次、倒计时和剩余进度。移入面板可直接暂停、开始或继续；右侧重置按钮清空整次计时进度并返回第一轮，保留任务和已累计专注时长。离开图标及面板约 0.3–0.4 秒后关闭，点击外部也可关闭；面板显示在普通窗口上方，支持全屏 Space，不抢焦点，关闭或操作超时都不会唤起主窗口。仅主动点击菜单栏图标或 Dock 才恢复主窗口。面板跟随应用浅色／深色主题，不创建常驻桌面浮窗或灵动岛。隐藏窗口时由原生时钟继续计算剩余时间；面板操作与主窗口共用计时状态。macOS 会保存用户调整后的图标位置；若图标不可见，检查系统设置 → 菜单栏 → 允许在菜单栏显示 → Focus On，并为菜单栏留出空间。
- 任务、时长、计时进度、提示音偏好与今日完成次数保存在 localStorage；macOS 应用使用独立的本地存储。一次完整安排记为一次专注。
- “今日已完成”后面的三横线打开历史任务：主页面和历史页上下相连，整张主页面向上滑出、历史页紧接着进入，如同卷轴。历史页仅展示任务记录，按完成日期倒序分组，任务标题使用浅绿色删除线；右上角箭头或 Esc 向下滑回主页面，返回后可添加新任务。支持系统减少动态效果；查看历史不会暂停计时。
- 每条历史任务右侧的垃圾桶可删除这条记录，刷新或重开应用后也保持删除；删除最后一条时清除空日期分组。删除历史记录不影响待办任务、当前计时和“今日专注”完成次数。
- 点击任务的完成按钮时保存完成时间、累计专注时长与分神次数。专注时长排除休息和暂停，重置计时保留该任务已经投入的时长；计时结束不会自动标记任务完成。分神次数仅计摄像头实际触发的宠物提醒，一次持续偏离只计一次。历史保存在本机；旧版已删除的完成任务无法追溯恢复。
- 浏览器版使用真实经过时间恢复计时，页面重载或休眠后会补算；浏览器关闭或系统休眠期间无法播放阶段提示音。macOS 应用在系统/显示器休眠、关窗口或正常退出时自动暂停。

## 设计

保留原稿的暖白底、灰绿强调色、圆形时钟和圆角输入框。采用 macOS 系统字体、低干扰动画与 `prefers-reduced-motion` 适配。较矮的桌面窗口使用紧凑布局，宽度不超过 600px 时切换为任务优先的纵向布局。

设置 → 外观主题提供「浅色 / 深色」二选一，默认浅色；选择即时生效并保存在本机，不随系统外观改变。浅色保留灰绿与橙色，深色使用荧光黄绿 `#D6E92F` 表示专注、灰紫蓝 `#B9C1DB` 表示休息及监测异常。强调文字与小按钮共用黄绿，普通文字使用中性白灰；悬停、焦点与历史记录配色从主题变量派生。任务页、设置与历史页统一切换。

`src/session.ts` 包含时间规则，`src/store.ts` 管理任务、历史与计时结算，`src/HistoryPanel.tsx` 展示历史，`src/Dial.tsx` 包含圆盘交互，`src/main.tsx` 组合界面，`src/styles.css` 包含布局和浅色设计变量。测试截图位于 `artifacts/`，历史页预览为 `history-desktop.png` 和 `history-mobile.png`。
